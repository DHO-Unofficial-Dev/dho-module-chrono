# 만료 일시와 타롯 종류

시간 보정은 PC의 현지 날짜와 시간을 기준으로 입력한다. 기본 입력 방식은 만료 일시이며 남은 시간 입력으로 전환할 수 있다. 만료 일시는 저장 시점부터 기본 기간 이내여야 한다. 실행 중인 타이머는 입력한 시각을 그대로 만료 시각으로 저장한다. 기본 기간과 실행 ID는 보존한다.

일시정지 중에는 입력한 시각과 저장 시각의 차이를 남은 시간으로 저장하며, 일시정지를 유지한다. 재개하면 저장한 남은 시간만큼 다시 계산한다. 오늘·내일 버튼은 날짜만 바꾼다. 지난 시각을 다음 날로 자동 변경하지 않는다.

타롯 종류만 새로 일시정지할 수 있다. Vault 항목의 이름·설명에서 타롯 관련 표현을 찾으면 등록 화면에 타롯을 제안하며, 사용자가 일반 아이템으로 변경할 수 있다. 기존 등록 항목의 종류는 자동 변경하지 않는다. 설정에서 직접 변경한다. 타롯은 기본 기간이 3시간이다. 다른 기간으로 실행 중인 항목은 정지 후 타롯으로 바꾼다.

이전 버전에서 일시정지한 일반 아이템은 저장된 시간을 보존한다. 편집·재개·정지는 가능하며, 재개 후 다시 일시정지할 수 없다. 업데이트 시 임의로 재개하거나 경과 시간을 추정하지 않는다.

HUD에서 실행 중인 타롯을 좌클릭하면 일시정지하고 다시 클릭하면 재개한다. 실행 중인 일반 아이템은 조작 메뉴를 연다. 대기·만료 항목은 좌클릭으로 시작한다.

## 동시 시작 연결

패널 카드의 사슬 버튼으로 함께 시작할 항목을 선택한다. 연결된 사슬은 강조색으로 표시한다. 연결은 배치 그룹과 별개이며, 다른 그룹이나 숨겨 둔 그룹의 항목도 함께 시작할 수 있다.

연결된 항목 중 하나를 패널 또는 HUD에서 시작하면 대기·만료된 연결 항목도 같은 저장 시각에 시작한다. 각자의 기본 기간을 사용한다. 이미 실행 중이거나 일시정지한 다른 항목은 만료 시각·남은 시간·실행 ID를 유지한다. 실행 중인 항목을 확인 후 다시 시작하면 직접 선택한 항목만 재시작하고, 나머지에는 같은 대기·만료 규칙을 적용한다.

정지·일시정지·재개·시간 보정은 개별 동작이다. 연결 저장이나 해제 자체는 시간을 바꾸지 않는다. 이 항목의 연결을 해제하거나 삭제하면 나머지 항목끼리의 연결은 유지한다. 연결 편집에서 제외한 기존 항목도 둘 이상이면 서로의 연결을 유지한다. 다른 연결에 포함된 항목은 기존 연결을 해제한 뒤 선택한다.

연결은 한 항목당 하나만 허용한다. 연결 편집 시 관련 항목의 버전을 함께 갱신해 오래된 편집 요청을 거절한다. 동시 시작은 단일 저장으로 확정되므로 일부만 시작된 상태를 저장하지 않는다. 연결 정보가 없는 이전 저장값은 연결 없는 상태로 읽는다.
