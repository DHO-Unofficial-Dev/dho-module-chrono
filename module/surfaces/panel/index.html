      공통 배치
      저장 공간 관리

      사용 중인 타이머가 없는 아이템 사본을 삭제할 수 있습니다.

        모션과 작은 장난

        시간과 클릭 위치는 그대로 두고, 아이콘에만 작은 움직임을 더합니다.

        시작·재개 반응, 부드러운 게이지와 만료 임박 표시

        아이콘이 2~4개일 때 드물게 움직입니다. 일시정지·만료 임박 항목은 쉬어요.

        Chrono HUD를 표시한 뒤 실행하세요. 자동 실행 대기와 켜기 설정을 건너뛰어 한 번만 확인합니다. 타이머는 변경하지 않습니다.

        시스템의 동작 줄이기가 켜져 있어 모션을 재생하지 않습니다.

        첫 그룹은 하나의 HUD로 표시됩니다. Ctrl+Shift+E로 공용 배치 화면을 열어 이동·확대할 수 있습니다. 알림·사운드는 아직 제공하지 않으며 타롯 일시정지는 수동입니다. 그룹을 숨겨도 SDK 제한으로 최소 40×40 입력 영역이 남습니다.
